# Ethnographic analysis of prompt modifiers

[[A taxonomy of prompt modifiers for text-to-image generation]] (§3) combines hands-on autoethnography with community observation and resource review to derive categories of prompt use.

## Source procedure

The author practiced with VQGAN–CLIP during October–December 2021, generated 885 images, participated in Twitter discussions, and reviewed shared prompts and community guides. Candidate categories were grouped inductively and revisited when new examples appeared. A presentation with text and images supported reflection, followed by summative review of taxonomy completeness and consistency.

The author reports that no new categories emerged after some weeks. This supports saturation within the encountered material, but the paper does not report independent coder agreement, a complete post corpus, or quantitative tests of modifier effectiveness.

## Adapting the taxonomy for thesis annotation

The following is a proposed procedure, not a protocol validated by the paper:

1. Define the unit of annotation: a phrase, reference image, or prompt-edit operation.
2. Record the six source categories and allow multiple labels when functions overlap.
3. Keep intended function separate from measured effect; an ineffective quality booster still has that intended role.
4. Record model/version, full prompt context, and uncertainty in assigning a category.
5. Check coding consistency on a sample, document disagreements, and test outcome claims with a separate experiment.

This method organizes practices and hypotheses. It is not an image-quality, alignment, or diversity metric.
